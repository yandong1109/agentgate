# Agent 测评系统简版需求

> **定位**：本文是产品需求的简版概览（入口）。完整需求陈述、优先级（P0–P3）与验收标准见 `requirements-baseline-zh.md`；本文与之不一致处（含 §8 的历史阶段划分），以基线为准。

## 1. 产品目标

为业务开发人员提供 Agent 和 Skill 的测试、问题定位与持续改进能力，形成以下闭环：

```text
创建 Agent / Skill
        |
        v
生成或维护测评集
        |
        v
配置评估器
        |
        v
执行测评任务
        |
        v
查看结果和 Badcase
        |
        v
分析原因并优化
        |
        v
更新 Agent / Skill / 测评用例
        |
        +-----------> 回归测评
```

系统需要回答四个核心问题：

1. Agent 或 Skill 是否达到上线要求？
2. 失败发生在哪里？
3. 应该修改 Agent、Skill、提示词，还是测评用例？
4. 修改后是否比原版本更好？

---

## 2. 测评范围

测评对象简化为两类：

| 对象 | 测评重点 |
|---|---|
| Agent | 意图识别、Skill 路由、多轮上下文、工具调用、最终输出 |
| Skill | 触发准确性、执行步骤、工具参数、输出格式、业务规则 |

系统第一阶段不再从产品层面区分单智能体、工作流或其他 Agent 实现形态，由执行适配器屏蔽底层差异。

Agent、Skill 及其版本由外部 Agent 平台管理。测评系统不创建、修改或管理这些资产，只通过外部 Agent 平台接口读取对象信息，并在测评任务中保存对象 ID、版本 ID 和必要快照。Demo Agent 和 Demo Skill 仅用于独立演示和端到端验证。

## 3. 核心对象

```text
外部 Agent 平台（外部资产源）
  |
  +-- Agent + AgentVersion
  |     +-- 包含多个 Skill
  |
  +-- Skill + SkillVersion
        +-- description
        +-- prompt
        +-- tools

测评系统
  |
  +-- TestTargetSnapshot
        +-- target_type: Agent / Skill
        +-- external_id
        +-- external_version_id
        +-- 测评时的必要不可变快照

Dataset
  |
  +-- DatasetVersion
          |
          +-- Case
                +-- 单轮或多轮对话
                +-- 正例 / 负例 / 边界
                +-- 难度
                +-- 标签和备注
                +-- 期望结果

Evaluator
  |
  +-- EvaluatorVersion
          +-- 规则评估器
          +-- LLM 评估器
          +-- 复合评估器

EvalTask
  +-- TestTargetSnapshot
  +-- DatasetVersion
  +-- EvaluatorVersion
  +-- 执行配置

EvalResult
  +-- 总体指标
  +-- CaseResult
  +-- Trace
  +-- Badcase
  +-- 优化建议
```

## 5. 前端页面与功能

### 5.1 总览

展示系统整体运行情况：

- Agent 数量、Skill 数量；
- 测评集及用例数量；
- 今日任务数、运行中任务数和失败任务数；
- 最近通过率趋势；
- 常见失败类型；
- 最近测评任务。

### 5.2 自动生成测评集

选择 Agent 后，系统直接读取：

- Agent Prompt；
- Skill 列表和 description；
- Skill Prompt；
- 工具定义；
- 输入输出定义。

不再要求用户额外填写“Agent 能力描述”。

生成的用例需要包含：

- 正例、负例或边界用例分类；
- 单轮或多轮类型；
- 难度；
- 场景标签；
- 期望路由、工具或输出。

本期删除：

- 安全合规用例类别；
- Token 消耗预估。

生成后必须允许人工修改，并保存为测评集版本。

### 5.3 测评集管理

支持：

- 创建、编辑、复制和删除测评集；
- JSON 和 Excel 导入导出；
- 单轮及多轮对话用例；
- 正例、负例、边界分类；
- 标签、难度和备注；
- 测评集版本管理；
- 历史任务绑定固定版本。

多轮用例示例：

```text
Turn 1 用户：我想申请贷款
Turn 1 期望：询问金额和期限

Turn 2 用户：80 万，30 年
Turn 2 期望：进入贷款申请 Skill

Turn 3 用户：我的申请能直接批准吗？
Turn 3 期望：查询征信并转人工审核
```

### 5.4 评估器管理

支持三类评估器。

#### 5.4.1 规则评估器

- JSON 结构校验；
- 必填字段校验；
- 字段类型校验；
- 字段值、范围和枚举校验；
- 正则及文本匹配；
- 工具名称和参数校验。

规则评估器在同一用例的评估链中优先执行。如果关键结构或字段校验失败，可根据任务配置终止后续评估。

#### 5.4.2 LLM 评估器

- 支持配置评分 Prompt；
- 输出分数、结论和原因；
- 支持平台公共 Key；
- 支持用户私有 Key；
- 私有 Key 必须加密保存，页面和日志不展示明文。

#### 5.4.3 复合评估器

- 组合多个规则或 LLM 评估器；
- 支持配置权重和通过条件；
- 第一阶段可只保留产品定义，组合语义在实现前单独明确。

后续扩展：

- 文件内容评估；
- 图片、音频、视频等多模态产物评估。

### 5.5 测评任务

任务配置包含：

- 选择 Agent 或 Skill 及其版本；
- 选择测评集版本；
- 选择评估器版本；
- 选择公共 Key 或私有 Key；
- 配置并发、超时和重试；
- 立即执行或预约执行。

任务状态：

```text
等待中 -> 运行中 -> 已完成
                  -> 已失败
                  -> 已终止
```

### 5.6 结果中心

总体展示：

- 总分和通过率；
- 按评估器统计；
- 按正例、负例和边界用例统计；
- 按难度统计；
- Agent 路由准确率；
- Skill 触发准确率；
- 工具调用正确率；
- 延迟和失败率；
- Badcase 分布。

用例详情支持：

- 查看输入、实际输出、期望结果和 Trace；
- 查看难度和备注；
- 修改难度、备注及用例内容；
- 将修改写入测评集新版本；
- 将该用例加入回归测试集；
- 重新执行单条用例。

修改用例时不覆盖历史任务使用的测评集版本。

### 5.7 调优中心

支持：

- Badcase 自动聚类；
- 聚类分布；
- 代表性失败用例；
- 根因分析；
- 优化建议；
- 路由结果混淆矩阵。

混淆矩阵示例：

```text
实际 预期       贷款审批   额度查询   还款计划
贷款审批           32          4          1
额度查询            3         27          2
还款计划            0          2         29
```

该矩阵用于识别容易被相互错误路由的 Skill。

## 6. Skill 静态分析

Skill 静态分析为独立能力，不需要执行真实测评任务。

```text
Agent Prompt
Skill A description --+
Skill B description --+--> 静态分析器
Skill C description --+        |
                              +-- Skill 冲突
                              +-- Skill 边界模糊
                              +-- description 重叠
                              +-- Prompt 与 Skill 不匹配
                              +-- 缺少兜底 Skill
```

调用时机：

1. 创建或更新 Agent 时；
2. 添加或修改 Skill 时；
3. 发起测评前主动调用；
4. 调优中心分析路由 Badcase 时。

输出只提供风险提示和修改建议，第一阶段不自动修改 Agent 或 Skill。

## 7. 版本与回归关系

```text
外部 Agent 平台 Agent A / version-1 --+
外部 Agent 平台 Skill S / version-3 --+--> TestTargetSnapshot
                                |
Dataset v5 ---------------------+--> EvalTask #101 --> EvalResult #101
Evaluator v2 -------------------+

修改失败用例
      |
      v
Dataset v6
      |
外部 Agent 平台修改 Agent Prompt
      |
      v
Agent A / version-2
      |
      v
EvalTask #102
      |
      v
与 #101 对比 -> 判断是否改进
```

历史结果不能被新版本覆盖。测评系统不拥有 Agent/Skill 版本，只记录外部 Agent 平台返回的版本引用和测评时快照。每个任务必须记录：

- Agent 或 Skill 的外部对象 ID 和版本 ID；
- 测评时的必要对象快照；
- 测评集版本；
- 评估器版本；
- 模型及执行参数；
- Key 类型，不记录明文 Key。

## 8. 实施优先级

### 8.1 第一阶段：核心 POC

- 提供 Demo Agent 和 Demo Skill，用于证明执行、Trace 和评估链路；
- 定义外部 Agent 平台对象读取适配器，POC 先由 Demo 适配器实现；
- 自动生成测评集；
- 测评集和多轮用例管理；
- 规则评估器，重点实现 JSON 结构和字段值校验；
- LLM 评估器及公共/私有 Key 选择；
- Agent 和 Skill 测评任务；
- 结果中心和用例回写；
- Skill 静态冲突分析；
- Badcase 聚类和混淆矩阵。

### 8.2 第二阶段：增强能力

- A/B 多版本对比；
- 公共 Key 队列及预约；
- 完整版本血缘图；
- 调优建议采纳闭环；
- 文件和多模态产物评估；
- CI/CD 上线门禁。
