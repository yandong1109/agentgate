# 能力域、语义契约与依赖方向（需求层）

> **定位**：本文件是 `requirements-baseline-zh.md` 的"需求层组织视图"——只用领域语言描述：这个评测系统有哪几块彼此独立的业务能力、它们之间共享哪些语义、谁依赖谁。**不含模块划分、包结构、接口、数据模型等任何设计内容。**
>
> **用途**：① 作为校验架构设计（refactor-1 的顶层域划分）是否对齐的标准；② 作为后续"按能力域切片"分发需求的地基。
>
> **边界提醒**：本文件里的"能力域"是**需求层业务能力**，不是设计层的"模块"。两者名字可能重合（好的设计会让模块对齐业务能力），但先后与含义不同——先有需求层的业务能力，后才被设计落地成模块。

## 1. 业务能力清单

| 能力 | 做什么 | 核心概念 | 关联需求 |
| --- | --- | --- | --- |
| 接入评测对象 | 把要评测的 Agent/Skill 接入，确定其版本，统一评测方式 | 评测对象、对象版本 | REQ-001/002/003 |
| 管理评测集 | 创建与管理用例、评测集，含多轮、期望、版本、导入导出、采样、自动生成、从结果页修正 | 用例、评测集、版本 | REQ-004~011 |
| 配置评测标准 | 定义与复用评测标准（确定性/语义/组合），以及结果的五种语义 | 评估器、评测标准、结果语义 | REQ-012~016 |
| 执行评测 | 发起并运行评测，含并发、超时、重试、状态、断点恢复 | 评测运行、状态 | REQ-017/018/019/020/036 |
| 判定与报告 | 产出指标、达标结论、报告、下钻、导出 | 结果、指标、门禁、报告 | REQ-021/022/023/025 |

## 2. 语义契约

跨多个能力、需要"生产方"与"消费方"对齐的语义。防切片跑偏的关键：这些语义在任何一个能力里都不该被单方面改写，必须在此统一定义、全局共享。

| 契约 | 语义 | 生产方 | 消费方 |
| --- | --- | --- | --- |
| 结果五态 | 通过/失败/待复核/不适用/评测出错；评测出错 ≠ 对象失败；不适用不计入通过率 | 执行评测 | 判定与报告、回归与对比、定位失败 |
| 门禁三要素分离 | 达标线、权重、阻断级三者分离，发起评测前配置 | 配置评测标准 + 发起时配置 | 判定与报告 |
| 评测集版本不可变 | 发布后内容不可变，改动走新版本 | 管理评测集 | 执行评测、判定与报告 |
| 可复现四要素 | 对象版本（REQ-002）+ 评测集版本（REQ-007）+ 评测标准（REQ-012）+ 门禁配置（REQ-022）全部固化 | 接入/评测集/标准/门禁分别产出 | 执行评测、判定与报告共同保证 |
| 用例期望语义 | 每条期望含"期待发生/不期待发生"，分应调用工具、禁止工具、业务状态、输出、规则；应调用与禁止不矛盾 | 管理评测集 | 配置评测标准、执行评测 |
| 对象只读边界 | 评测对象由外部拥有，本系统只读引用，不创建/修改/管理 | 接入评测对象 | 所有能力 |
| 运行状态生命周期 | 排队中 → 运行中 → 完成/失败/取消 | 执行评测 | 判定与报告、回归 |

## 3. 概念依赖方向

```
接入评测对象 ─┐
管理评测集   ─┼──→ 执行评测 ──→ 判定与报告 ──┬─→ 回归与对比（复用执行）
配置评测标准 ─┘                              ├─→ 定位失败与改进（消费结果）
                                             └─→ 人工标注（消费结果 → 反哺评测集）

静态检查    ── 独立，基于 管理评测集 + 配置评测标准（不执行）
对比实验    ── 依赖 执行评测 + 判定与报告（后置）
安全与审计  ── 横切贯穿所有能力（无方向）
```

依赖清单（谁依赖谁）：

- 执行评测 ← 依赖 ← 接入评测对象 / 管理评测集 / 配置评测标准
- 判定与报告 ← 依赖 ← 执行评测
- 回归与对比 ← 复用 ← 执行评测；并依赖 ← 判定与报告
- 定位失败与改进 ← 依赖 ← 判定与报告（结果 + 调用链）
- 人工标注 → 消费 判定结果 → 反哺 管理评测集（形成跨时间的"改进闭环"，这是领域固有闭环，不是编译/运行期依赖环）
- 对比实验 ← 依赖 ← 执行评测 + 判定与报告
- 静态检查 ← 独立观察 管理评测集 + 配置评测标准（不执行）

**无环校验**：主链单向（评测集/标准/对象 → 执行 → 判定）；下游能力（回归、定位、标注、实验、静态检查）均不产生编译期回指。"人工标注 → 反哺评测集"是跨时间的业务闭环，不构成结构环。
